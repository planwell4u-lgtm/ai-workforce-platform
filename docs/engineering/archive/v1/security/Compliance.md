# Compliance and Auditing Standards

Overview of regulatory frameworks and compliance targets.

## SOC 2 Type II
- **Audit Trails:** Capture access to client database and system modifications.
- **Log Retention:** Keep system audits for 12 months minimum.

## GDPR / CCPA
- **Right to Be Forgotten:** Implement automated pipeline to purge user account information upon deletion request.
- **Data Portability:** Allow users to export historical conversation transcripts.
