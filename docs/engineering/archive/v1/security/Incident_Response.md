# Security Incident Response Plan

Action guide for responding to active security breaches or vulnerability exposures.

## Incident Lifecycle

1. **Detection:** Alerts from vulnerability scanning tools, intrusion detection systems, or external reports.
2. **Containment:**
   - Revoke compromised credentials/keys.
   - Restrict network security group access.
   - Isolate affected container clusters.
3. **Eradication:** Deploy patches addressing the vulnerability source.
4. **Recovery:** Restore clean backups if data modification occurred.
5. **Notification:** Inform affected users and regulators if PII exposure has occurred.
