# 31.1 PostgreSQL Core Schema

**Version:** 1.0\
**Phase:** 31 -- Database Architecture\
**Status:** Draft

## 1. Purpose

This document defines the core PostgreSQL architecture for the AI Voice
Agent SaaS Platform.

## 2. Design Goals

-   Multi-tenancy
-   Enterprise security
-   High availability
-   AI workloads
-   Vector search
-   Real-time conversations
-   Billing
-   Compliance

## 3. Technology Stack

  Component   Technology
  ----------- ----------------
  Database    PostgreSQL 16+
  Vector      pgvector
  Cache       Redis
  ORM         SQLAlchemy 2
  Migration   Alembic
  API         FastAPI

## 4. PostgreSQL Extensions

``` sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
```

-   billing
-   audit
-   system

## 6. Core Standards

-   UUID primary keys
-   `tenant_id` on all tenant-owned tables
-   UTC timestamps (`TIMESTAMPTZ`)
-   Row Level Security
-   Soft deletes (`deleted_at`)
-   Optimistic locking (`version`)
-   JSONB for flexible metadata

## 7. Redis Responsibilities

-   Conversation state
-   Agent session state
-   Cache
-   Rate limiting
-   Queues

Redis is **not** the system of record.

## 8. Object Storage

Store recordings, PDFs, exports and images outside PostgreSQL.
