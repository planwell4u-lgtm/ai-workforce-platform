# Overview

Event Driven Automation defines the architecture for triggering automated workflows based on real-time events generated by users, systems, applications, AI agents, and external services.

Instead of continuously polling systems, the platform reacts to meaningful events and executes the required automation workflows.

This enables:

- Real-time processing
- Loose system coupling
- Scalable automation
- Faster business responses
- Intelligent AI workflows

---

The Event Driven Automation system provides:
